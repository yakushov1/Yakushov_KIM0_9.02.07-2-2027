# Чудо Обувь — Приложение для заказа обуви

## Описание
Десктопное приложение для торговой компании «Чудо Обувь». Позволяет просматривать каталог, искать товары, оформлять заказы, а также управлять заказами (для администратора и менеджера).

## Технологии
- Python 3.14
- PyQt6 (графический интерфейс)
- SQLAlchemy + pyodbc (подключение к MS SQL Server)
- Pandas (работа с данными)
- MS SQL Server (база данных)

## Роли
- **Гость**: просмотр каталога (без оформления заказа).
- **Авторизованный пользователь**: просмотр, поиск, фильтрация, оформление заказа.
- **Менеджер**: всё выше + просмотр списка заказов, удаление заказов.
- **Администратор**: всё выше + редактирование даты заказа, удаление позиций.

## Установка и запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Убедитесь, что SQL Server запущен и база `ChudoObuv` создана.
3. Запустите: `python main.py`
